# ドッジボールゲーム Ver.1.5

小学生でも楽しめる、見下ろし型の2Dドッジボールゲームです。青チームと赤チームが、各チーム同じ内野人数と初期外野1人で対戦します。プレイヤーは青チームの1番を試合終了まで操作し、ほかの選手はCPUが操作します。

## あそび方

PCのブラウザで `index.html` を開き、「各チームの初期内野人数」で1〜10人（初期設定は3人）を選んで「スタート」を押します。試合中は人数が固定され、試合終了後に次の試合の人数を選べます。インストール、ビルド、外部ライブラリ、APIキーは不要です。

| 操作 | キー |
| --- | --- |
| 「▼ あなた」の選手を移動 | 矢印キー / WASD |
| 一番近い相手内野に投球 | Space |
| 内野からは一番近い味方外野へ、外野からは一番近い味方内野へパス | P |
| 相手の投球をキャッチ | 当たる直前に C |
| 地面のボールを拾う | ボールに近づく |

キャッチの受付時間は画面の「キャッチ有効時間」で0.25秒・0.4秒（初期設定）・0.6秒・1.0秒から選べます。Cキーを押した瞬間の設定が適用されます。再使用までの時間は1秒で固定です。相手の攻撃ボールが飛んでいるときのみ発動できます。頭上の「▼ あなた」と青いリングが操作選手の目印で、黄色いリングはボール保持者の目印です。「はじめから」で現在の人数設定を使って試合をやり直せます。

## 外野と勝敗

コート中央は青・赤の内野です。赤外野は青内野の上・左・下、青外野は赤内野の上・右・下を囲むU字型です。外野選手は自チームのU字型エリア内を移動できます。上下外野の中央寄り部分は投球禁止ですが、移動・捕球は可能です。赤い区画線は外枠全幅の3分の1と3分の2の位置を示します。左右外野の投球は可能です。開始時は赤の初期外野が左、青の初期外野が右に立ち、アウトになった選手も自チームと同じ側の外野へ移ります。960×560のコートで、左右の外野幅は56px、上下の外野幅は52pxです。

- 相手内野への攻撃と、味方の内野・外野間のパスができます。パスは受け手が受け取り、軌道に入った相手内野はアウトにならずにボールを奪えます。外野からの攻撃投球が味方内野に届いたときも味方内野が自動でキャッチし、アウトにはなりません。相手チームの外野も飛来したボールをキャッチできます。
- 相手の攻撃が内野に当たると、その選手はチームの外野へ移動します。青1番がアウトになった場合は、そのまま外野で移動・投球・味方内野へのパスができます。内野に戻った後も青1番を操作します。
- 「復帰可」の外野は、自分の攻撃を相手内野に当てると内野に戻れます。「初期」の外野は試合を通して外野を担当します。パスやキャッチされた攻撃での復帰はありません。
- 相手の内野を0人にした時点で勝ちです。内野1人で始めた場合、その選手がアウトになると試合が終わります。試合時間に制限はありません。

内野AIはボールを取るとセンターライン付近まで前進し、相手内野への投球か味方外野へのパスを選びます。相手の攻撃は前後どちらから来ても軌道を予測して回避します。青の内野CPUは、当たりそうな球をキャッチすることもあります。外野CPUは担当エリアを移動してボールを拾い、飛んできた攻撃球を自動でキャッチします。ボールを取ったら相手内野への攻撃か味方内野へのパスを選びます。地面のボールが6秒間拾われないと、中央付近に戻ります。

「ゆっくり／ふつう／はやい」でボールの初速を選べます。試合開始から10秒ごとに初速の1/6ずつ加速し、120秒で初速の3倍に達します。飛んでいるボールの速度は投球・パス時点で決まります。

## CPUの強さ（Ver.0.8）

ゲーム画面の「CPUの強さ」で「弱い／ふつう／強い」を選択できます。初期設定は「ふつう」です。
赤チームCPUのみ、投球の狙いの精度・回避の発動確率・移動速度・ボール保持から投球までの待ち時間を変更します。
- 弱い：回避を試みる確率25％、移動速度0.8倍、投球準備時間1.6倍、狙いのばらつき大
- ふつう：回避100％（Ver.0.7相当）、移動速度1倍、投球準備時間1倍、狙いのばらつきなし
- 強い：回避100％、移動速度1.22倍、投球準備時間0.6倍、狙いのばらつきなし

回避の確率は相手の投球ごとに判定し、実際の回避成功率を保証するものではありません。青チームの味方AIの強さは変更しません。試合中の設定変更は次の動作から反映します。

## 開発とテスト

- `index.html` と `style.css` は画面と操作説明を担当します。
- `game.js` はCanvas描画、入力、AI、ゲームルールを担当します。
- `node --test` で1〜10人の初期配置、1・3・5・10人の試合進行、操作選手の固定、CPUの行動、投球・パス、復帰、攻守交代、勝敗、速度、長時間動作を検証できます。

HTTP経由で確認する場合は、リポジトリで `python3 -m http.server 8000` を実行してください。ゲームはPCのキーボード操作向けです。

## 外野の素早い投球（Ver.0.9）

外野選手は捕球・ボール取得後、約0.25〜0.4秒で投球または内野へのパスを行います。CPUの難易度が「弱い」でも、外野の待機時間は長くなりません。外野は相手内野への攻撃を優先し、初期外野がボールを受け取った際は一部の状況で味方内野へパスします。外野同士のパス禁止と、復帰可能な外野の攻撃による復帰条件は維持します。

## U字型の外野とCPU調整（Ver.1.0）

- 当時の初期配置：各チーム内野3人＋外野1人。アウトになった内野は外野へ移動し、攻撃を成功させると復帰可能です。
- 外野は相手内野の上・横・下を囲むU字型。コート上部と下部の中央側（外枠の幅の中央3分の1に該当する区画）は投球不可ですが、移動とキャッチはできます。外野の左右端および上下の外側3分の1では投球できます。
- 外野からのボールが味方内野に戻った場合、投球／パスに関係なく自動キャッチします。外野選手も飛来する攻撃球を自動キャッチします。外野同士のパスは引き続き禁止です。
- CPU「ふつう」はVer.0.7相当の毎回の軌道回避判断・正確な狙いを復元しました。「弱い」「強い」の選択肢は維持します。
- 外野の素早い投球（約0.25〜0.4秒）、キャッチ有効時間の選択、ボール加速の仕様は維持します。

## サイド外野の投球不足による攻守交代（Ver.1.3）

外野からの攻撃投球が誰にも当たらないまま終了し、中央のセンターライン（Canvas x=480）を越えていなかった場合は相手チームのボールです。相手チームで最もボールに近い内野選手にボールを渡し、プレーを継続します。センターラインを越えたかどうかは飛球中の軌跡で判定します。

コートの形状上、外野から相手内野に当てる投球がセンターラインを通らない場合があります。そのような命中や途中のキャッチは従来どおり有効とし、センターライン未通過の反則判定は誰にも当たらず終了した攻撃投球にだけ適用します。味方へのパスには適用しません。

## 外野からの自チーム外野への再取得を防止（Ver.1.5）

外野選手の攻撃投球は、飛行中だけでなく投球終了後に地面へ落ちた場合も、同じチームの外野が捕球・再取得して投げ続けることを禁止しました。外野からの攻撃投球が味方外野エリア内で終わった場合、またはその球を同じチームの外野選手が拾おうとした場合は、相手チームの内野にボールを渡します。相手内野への有効な命中、味方内野への捕球、通常の内野・外野パスのルールは維持します。

## 外野の無効投球の0.5秒表示（Ver.1.5）

外野の投球がセンターライン未通過などの理由で無効になった場合、球が止まった地点にそのまま0.5秒間表示します。この間はボールを誰も拾えず、AIも再投球できません。0.5秒後に相手内野へボールを渡して試合を再開します。味方外野による再取得禁止、U字型コート、CPU難易度、捕球時間設定は変更していません。
